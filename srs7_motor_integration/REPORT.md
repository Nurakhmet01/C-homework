## 1. Цель и принцип

**Цель.** Подключить к схеме из СРС №6 (HC-SR04, кнопка, три LED) драйвер L298N с DC-мотором и реализовать управление скоростью и направлением по измеренному расстоянию.

**Главный принцип.** Симулятор подтверждает, что алгоритм и виртуальные соединения работают в его модели. Он не доказывает отсутствие токовых бросков при реверсе, просадки питания мотора, нагрева моста L298N, ЭДС самоиндукции и помех по цепям питания. Все выводы ниже относятся только к модели.

## 3. Конфигурация стенда

| Узел | Подключение | Требование |
| --- | --- | --- |
| HC-SR04 | VCC → 5V; GND → GND; TRIG → D9; ECHO → D10 | Общая земля с Arduino |
| Кнопка | D2 ↔ кнопка ↔ GND | `INPUT_PULLUP`: отпущена = HIGH, нажата = LOW |
| Красный LED | D13 → резистор 220/330 Ом → LED → GND | Горит при расстоянии < 20 см |
| Жёлтый LED | D12 → резистор  220/330 Ом → LED → GND | Горит при 20–50 см включительно |
| Зелёный LED | D11 → резистор  220/330 Ом → LED → GND | Горит при > 50 см |
| L298N, логика | IN1 → D5; IN2 → D6; ENA → D3 (PWM) | Направление и скорость |
| L298N, питание логики | Vss (5V) → 5V Arduino; GND логики → общий GND | **Критично:** без общей земли логика не работает |
| L298N, силовое питание | Vs → отдельный источник 7–12 В; GND силовой → общий GND | Отдельный источник для мотора |
| DC-мотор | OUT1 и OUT2 → клеммы мотора | Полярность задаёт направление вращения |

Инженерные правила стенда:

- общий GND между Arduino и L298N обязателен;
- у каждого LED собственный токоограничивающий резистор;
- при отпущенной кнопке мотор остановлен, все LED выключены, измерения приостановлены;
- ошибка датчика (тайм-аут `pulseIn`) переводит мотор в СТОП, а не в режим «путь свободен».

### 4.2 Таблица истинности L298N (канал A)

| IN1 | IN2 | ENA | Поведение мотора |
| --- | --- | --- | --- |
| LOW | LOW | 0 (LOW) или любое | При ENA = 0 мост отключён, мотор не приводится: **остановка выбегом** (по инерции). При ENA = HIGH и IN1 = IN2 = LOW по даташиту L298 нижние ветви открыты: быстрая остановка (торможение) |
| HIGH | LOW | PWM (1–255) | Вращение в одну сторону (условно «вперёд»: OUT1 +, OUT2 −), скорость пропорциональна скважности ШИМ |
| LOW | HIGH | PWM (1–255) | Вращение в **обратную** сторону («назад»), скорость задаётся ШИМ |
| HIGH | HIGH | PWM (1–255) | **Торможение**: обмотка мотора замкнута, вал быстро останавливается |


### 4.3 Прогноз поведения (кнопка нажата)

| Расстояние | Мотор | ENA (PWM) | LED |
| --- | --- | --- | --- |
| 10 см | СТОП | 0 | Красный |
| 20 см | Вперёд (граница: диапазон 20–50 включительно) | 120 (≈47%) | Жёлтый |
| 35 см | Вперёд | 120 (≈47%) | Жёлтый |
| 50 см | Вперёд (граница: включительно) | 120 (≈47%) | Жёлтый |
| 70 см | Вперёд | 255 (100%) | Зелёный |
| Кнопка отпущена | СТОП | 0 | Все выключены |

### 4.4 Правило безопасного состояния

Если `pulseIn()` вернул 0 (тайм-аут эха): `IN1 = LOW`, `IN2 = LOW`, `ENA = 0` (мотор СТОП), **все три LED выключены**, в Serial выводится сообщение об ошибке.

Обоснование: отсутствие эха не означает «путь свободен». Датчик может не видеть препятствие (поглощающая или наклонная поверхность, объект вне дальности), может быть оборван ECHO или пропало питание датчика. Поэтому безопасное действие по умолчанию — остановка.

## 5. Этап 2 — Базовая виртуальная схема

### 5.1 Алгоритм

| Расстояние | Мотор | ENA PWM | LED |
| --- | --- | --- | --- |
| < 20 см | СТОП | 0 | Красный |
| 20–50 см | Вперёд | 120 (≈47%) | Жёлтый |
| > 50 см | Вперёд | 255 (100%) | Зелёный |
| Ошибка датчика | СТОП | 0 | Все выключены |
| Кнопка отпущена | СТОП | 0 | Все выключены |

Измерения выполняются раз в 100 мс без `delay()` (через `millis()`), тайм-аут `pulseIn` — 30 000 мкс (≈5 м, с запасом по дальности датчика).

### 5.2 Код

Полный скетч: [`code/srs7_motor.ino`](srs7_motor_integration/code/srs7_motor.ino). Ключевая логика:

```cpp
bool validMeasurement = readDistanceCm(cm);
if (!validMeasurement) {          // тайм-аут эха -> безопасный стоп
  safeStop();
  Serial.println(F("ERR: echo timeout -> STOP"));
  return;
}
if (cm < NEAR_CM)        { motorStop();          setLeds(true,  false, false); }
else if (cm <= FAR_CM)   { motorRun(PWM_MID);    setLeds(false, true,  false); }
else                     { motorRun(PWM_FAR);    setLeds(false, false, true ); }
```

Реверс для теста №8 включается константой `#define MOTOR_FORWARD 0` (IN1 и IN2 меняются местами).

### 5.3 Частота ШИМ на ENA

На Arduino UNO пин D3 по умолчанию работает на ≈490 Гц (Timer2, делитель 64: 16 МГц / 64 / 510), то есть **ниже 1 кГц**. Требование задания: не подавать ШИМ ниже 1 кГц без проверки. Вариант решения — `PWM_HIGH_FREQ 1` (делитель 8, ≈3,9 кГц на D3/D11).

- Использованная частота: 490 Гц

## Важные предупреждения для L298N

- Общий GND между Arduino и L298N обязателен.
- Не утверждается, что мотор «защищён от токовых бросков»: симулятор этого не моделирует.
- ШИМ на ENA ниже 1 кГц не используется без проверки (см. п. 5.3).
- Провода под питанием не отключаются.
